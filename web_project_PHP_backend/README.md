# Overview

This repository serves as a portfolio collection of PHP-based full-stack web development projects.

The projects demonstrate practical implementation of frontend development, backend programming, authentication systems, database management, and responsive user interface design using PHP and MySQL.

Each project is maintained inside its own folder with a dedicated README containing complete documentation, screenshots, architecture diagrams, installation instructions, and implementation details.

# Projects Included

## 1. 🍽️ Swaad Ghar – Restaurant Management Website

### Overview

Swaad Ghar is a restaurant and recipe management website developed using PHP, MySQL, HTML, CSS, and JavaScript.

The project demonstrates complete full-stack web development fundamentals including user authentication, database connectivity, session management, and responsive frontend design.
